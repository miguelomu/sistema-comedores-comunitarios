# Sistema de Gestión de Comedores Comunitarios

## Descripción
Sistema educativo desarrollado en Python para gestionar comedores comunitarios, incluyendo inventario de alimentos, registro y consulta de beneficiarios y evaluación de vulnerabilidad.

## Tecnologías
- **Lenguaje**: Python 3.7+
- **Patrón**: MVC (Modelo-Vista-Controlador)
- **Librerías**: Solo librerías estándar de Python

## Características principales
- ✅ Gestión de 15 comedores en Bogotá
- ✅ Control de inventario por categorías
- ✅ Registro y evaluación de beneficiarios
- ✅ Sistema automático de puntajes de vulnerabilidad
- ✅ Distribución inteligente de alimentos

## Cómo usar
1. Clona este repositorio
2. Ejecuta: `python main.py`
3. Selecciona un comedor y explora las opciones

## Estructura del proyecto
├── main.py # Punto de entrada
├── models.py # Clases de datos (Comedor, Alimentos, Beneficiario)
├── views.py # Interfaz de usuario
├── controllers.py # Lógica de negocio
└── README.md # Este archivo
